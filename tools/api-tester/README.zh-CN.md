# 本地语音接口自测页

这个目录是一个只在本机打开的测试页。它用 Python 标准库把请求转到你填写的 Piper / Phonon 地址，避免浏览器直接跨域。它不修改生产服务，也不读取令牌文件。

## 启动

在本目录执行：

```text
python app.py --host 127.0.0.1 --port 8133
```

Windows 可以双击 `start.bat`。它会先找 `py -3`，找不到再用 `python`。路径里有中文或空格也可以。

然后打开：

```text
http://127.0.0.1:8133/
```

端口被占用时，程序会退出并说明原因。换一个端口即可，例如：

```text
python app.py --host 127.0.0.1 --port 8134
```

这不会结束已经在跑的语音服务。

## 令牌

页面上的令牌框默认是空的。它不写入 localStorage，不放进网址，也不写日志。令牌只随你点击的那一次请求，发往你填写的目标地址。

若令牌已经保存在当前用户主目录，文件是：

```text
Path.home() / ".local-tts-api" / "client-token.txt"
```

在已验证的这台 Windows 上，这就是当前用户文件夹下的 `.local-tts-api\client-token.txt`。需要使用时自己打开并粘贴。本程序不会自动读取。

公网地址必须是 https，证书校验不能关闭。只有 `localhost` 或 `127.0.0.1` 可以用 http，便于开发。地址不能带用户名、密码或 `#` 片段。

默认地址是 `https://124.222.128.61`，可以改。

## 能测什么

- 测试连接：`GET /api/health`
- 加载音色：Piper 与 Phonon。不把 Pocket 放进引擎选择
- 按接口返回的语言、音色、说话人组装请求
- 合成、播放和下载整段 WAV
- 显示 HTTP 状态、引擎、采样率、音频时长和合成耗时

「停止等待」只取消浏览器这一次等待，不能取消服务端已经开始的推理。Phonon 健康字段里的 `inferenceReady: false` 表示进程没有常驻，不等于不能合成。
